# HeyPay

**Pay any QRPH merchant in the Philippines straight from your Stellar balance.**

In the Philippines, millions of merchants accept QRPH — the central bank's national QR payment standard — but anyone holding XLM has no way to spend it there. The only path today is a manual grind: off-ramp crypto on an exchange, withdraw pesos to a bank, then finally pay. Several apps, several fees, several minutes — and it defeats the entire point of holding a spendable balance. HeyPay closes that gap. A payer scans any existing QRPH code — the same one every merchant already accepts — confirms a live XLM→PHP quote, and HeyPay moves the XLM on Stellar, converts it to pesos, and settles PHP directly into the merchant's bank account. The merchant does zero new integration and receives ordinary pesos; the payer just spent crypto in the real world. For Stellar, this is the missing last mile: a concrete instance of everyday spending utility for XLM in one of the network's most active real-world corridors, turning a held balance into a payment an ordinary merchant already knows how to accept.

**For reviewers:** HeyPay is a feature-complete, production-shaped MVP — every payer, merchant, and admin flow works end to end, from custodial wallet funding and camera-based QR scanning through live settlement tracking to admin retry/refund controls, backed by an automated test suite and continuous integration. To demonstrate the full flow without moving real money, the app runs in configurable provider modes (a fully mocked mode and a staging-exchange mode), so you can trace a payment from scan to peso settlement safely. We've deliberately scoped v1 to a single asset and a single conversion rail to prove the bridge works before generalizing it. The accompanying pitch deck lays out how HeyPay plugs into Stellar's native rails next — SEP-based anchors, USDC, on-chain path payments, and Soroban escrow — to grow from one focused application into reusable Stellar infrastructure, and a go-to-market plan that scales from the Philippines outward across APAC and beyond.
