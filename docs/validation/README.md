# Validation package

How to reuse HeyPay's Soroban settlement escrow, and the on-chain proof of
each claim of its Instawards sprint, on Stellar Testnet.

- [Integration guide](integration-guide.md): copyable code to deploy the escrow, deposit, release and refund, refund after the deadline, use USDC, and sign with Freighter.
- [SDK and API reference](escrow-sdk.md): every escrow function, error and event, the TypeScript client, and the own-wallet API.
- [On-chain receipt list](receipts.md): every settlement, refund and contract transaction of the sprint, checked on Testnet.
- [Verification page](verify.md): each claim with one Stellar Expert link and what you should see there, for a non-technical reviewer.
- [Demo script](demo-script.md): the shot list and narration of the technical demo.
